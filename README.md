# maestroml
ML Prediction at Scale hosted on a FastAPI web server

MaestroML performs machine learning predictions using linear regression and moving average models for financial, operational & demand data. Quickly process up to 20,000 time series using linear regression, rolling moving average, auto-regressive moving average, or exponential weighted moving average models. Optimized for speed, high-volume, and scale.
